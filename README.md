# Gmarc's Gen 2 Johto Alive

Three mods in one install for Gold, Silver and Crystal, so the world outside
battles feels inhabited.

## Features

- **Wilds of Kanto** — wild Pokémon live on the map: they spawn around you,
  idle, roam, chase, and can be caught in the overworld with a ball. Each part
  has its own setting.
- **Free Fly** — a party Pokémon that knows FLY carries you over the world and
  lands where you choose. Altitude, speed and encounters are configurable.
- **Wild Skies** — birds overhead, with their own density and size settings,
  and their own encounters.

Every part has its own options; all 38 settings are in the mod's list, each with
a one-line explanation.

## Install

Import the release ZIP in the mod list, enable it for Gold, Silver or Crystal,
and restart. Disable the separate Free Fly, Wild Skies and Wilds of Kanto mods —
they can't run together.
